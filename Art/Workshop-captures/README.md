# Workshop gallery captures

The three PNG files in this directory are the approved Flavor Text Extended Workshop gallery images, generated by
`Tests/Pickle/Mod/Pickle/Features/06-workshop-captures.feature` on 2026-09-22. They are optimized 1600x900 PNGs,
each below Steam's 2 MB limit.

Upload them to Steam in filename order:

1. `01-katsudon.png`
2. `02-two-dishes-at-once.png`
3. `03-medium-boiled-egg.png`

They use the `nelim-zen-meadow-studio` presentation fixture with the central-emblem camera frame. The meal card is
intentionally retained while screenshot mode hides the HUD and Pickle-owned windows. See `../../PUBLICATION.md` for
the display rationale and upload record.

`source/` holds the original 1920x1080 captures. Keep those files for future re-encoding or visual comparison; upload
only the optimized files at this directory's root.
